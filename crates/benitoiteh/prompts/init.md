Create an AGENTS.md file in the project directory for coding agents that will work in this project.

First inspect the project: list the top-level files and directories, and read the build, test and configuration files and the README if present. Then write AGENTS.md with these sections, keeping each short and specific to this project:

- Project overview: what the project is and its main components.
- Build and test: the exact commands to build, test, lint and format, as found in the project files.
- Code style: conventions that are visible in the code or configuration.
- Layout: where the main source, tests and documentation live.

Only state facts you found in the project. Do not invent commands or conventions. Keep the file under 200 lines. Do not change any other file.
