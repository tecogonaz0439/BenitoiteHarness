Implement main.bnt to read orders.json, a JSON array of order objects. Each order has a string region and a string status; amount, when present, is an integer. Exclude orders whose status is "cancelled". A missing amount is 0; such an order still contributes to the count. Group by region and print one line per represented region in ascending, case-sensitive name order: `<region>: <count> orders, <amount>`. Do not print a total or a heading. For an empty array print nothing. Input strings are ASCII and amounts are nonnegative integers. The examples in materials/1/ show source batches and intermediate regional subtotals. Use them as investigation material for this implementation.
