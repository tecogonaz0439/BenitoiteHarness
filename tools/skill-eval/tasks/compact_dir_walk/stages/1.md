Implement main.bnt to recursively scan docs/ and print the relative path of each regular file whose extension is .md, one path per line in ascending case-sensitive name order. Use / separators and no heading or footer. Exclude every directory component beginning with . and every directory component exactly named drafts, at any depth. These rules apply to directories: a regular file such as .visible.md is eligible. The root itself is supplied explicitly and its name is not an exclusion. Inputs contain ASCII names, ordinary files and directories, and no symbolic links. Empty results produce no stdout. materials/1/ lists observed paths and intermediate selections, including excluded subtrees.
