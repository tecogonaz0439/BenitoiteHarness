# 未決事項

本書は、設計書の【未決】【要検証】の事項を `BH-nnn` の番号で管理する。番号は分野ごとに十の位をそろえて振り（00 番台は全体とエージェント、20 番台は処理系との連携、30 番台は提供者、40 番台は安全、50 番台は画面と CLI、60 番台は実装と性能、70 番台は品質、80 番台は試作の後、90 番台は 40 番台に入りきらない安全の項目）、詰めない。閉じた項目も消さずに「閉じた」と書く。

「章」の列には関係する章を並べる。各章の冒頭の「未決事項」には、その章で決める項目を挙げる。

各項目の「決める時期」は、[ロードマップ](00-overview/00-03-roadmap.md)の段階で示す。
