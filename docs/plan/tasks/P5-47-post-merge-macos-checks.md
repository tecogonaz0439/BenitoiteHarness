# P5-47 取り込みの後の macOS での確かめと直し

- 状態: 完了
- 依存: P5-42〜P5-46

## 目的

P5-42〜P5-46 を `gamou` に取り込んだ（`86ae436`）後に、Linux だけで確かめていた項目を macOS で確かめ、見つけた不具合を直す。

## 経緯

本作業は、2026-11-04 にオーケストレータ（Claude Code）が設計者の指示で行った。設計者は、取り込みの前の確かめを行わず、取り込みの後に macOS が要る確かめを行うこと、見つけた不具合とレビューをオーケストレータが行うことを指示した。直しは作業用のブランチ `fix/2026-11-04-macos-checks` で行い、`gamou` に取り込んだ（`9576cba`）。安全に関わる変更は、サブエージェント二つにレビューさせ、オーケストレータが確かめた。

## 作ったもの

- `tests/sandbox_bash.rs`: OS のサンドボックスの中でコマンドを動かす `bash` のテストを `tests/tools_bash.rs` から移し（実装プラン 00-common「検査」）、macOS の中継のテストと、`PATH` の大小文字の違う綴りの行を加えた。`scripts/check.sh` は、このファイルを Landlock のないコンテナで飛ばす。
- 通信の中継の直し: macOS で `::1` の同じ番号にも待ち受ける、合言葉を呼び出しごとにして最初に確かめる、コマンドが終わったら確認をやめる、断ったドメインを尋ね直さない、答えを待つ確認の上限、頭を読む時間の上限、要求の行の制御の文字の拒否、機械自身のアドレスの拒否（`web_fetch` も）。
- `.agents` の直し: APFS が畳む長い s（U+017F）の綴りを守る名前とみなす、根の直下の守る名前のリンクの先を守る、macOS で守る名前のリンクがあればサンドボックスを掛けない、守る名前の下にプロジェクトを作らない。

対応する設計書は、01-03「web_fetch」「書く道具のパスの規則」、03-02「通信の中継」「.agents の守り」「読ませないホームの場所」「主のプロセスの守り」、03-03「通信の確認」である。BH-119 を閉じ、BH-118 を【未決】にした（BH-118 は、同日に設計者が限界と決めて閉じた）。

## 確かめた結果

[取り込みの後の macOS での確かめ](../results/P5-47-macos-checks.md)に書いた。直した後の全体の検査は、macOS、aarch64 の Linux、x86_64 の Linux のどれでも終了状態 0 だった。

## 残したこと

- 制限モードの秘密の名前を Seatbelt の正規表現の規則に改めるかの判断。BH-118 は、2026-11-04 に設計者が限界として書くと決めて閉じた。
- レビューで後に回した指摘（記録の「直さなかったレビューの指摘」）。
- 実際の端末のエミュレータでの OSC 9 の表示と外部のエディタの確かめ。
