# P4-08 `/` で始まるコマンド

## 目的

対話の画面の `/` で始まるコマンド（`/help`・`/status`・`/compact`・`/rewind`・`/new`・`/quit`）を作る（設計書 05-02 の「`/` で始まるコマンド」）。圧縮（P4-01）、巻き戻し（P4-03）、対話の画面（P4-06・P4-07）の口を使う。あわせて、P4 で加えた主のプロセスの操作を含めて、安全の性質のテストを通し直す（ロードマップの P4 の完了条件）。

## 作るもの

### 1. 入力の解釈

- 入力欄の文が `/` で始まり、一連の処理の途中でないときは、コマンドとして解釈する（途中なら、`/quit` だけを受け付け、ほかは「処理の途中では使えない」と示す）。先頭の語がコマンドの名前、残りが引数である。知らない名前は、`/help` を案内して示す（LLM に送らない）。`//` で始まる文は、先頭の `/` を一つ除いた依頼として送る。
- コマンドは入力の履歴に入れる。

### 2. コマンド

- `/help`: コマンドと入力の操作の一覧（05-02 の表）を示す。
- `/status`: セッションの ID、モード、提供者とモデル、処理系のパスと版（P2 の処理系の連携まで「not checked」）、サンドボックスの方針、使ったトークンの量（入力、キャッシュから読んだ量、キャッシュに書いた量、出力。費用は示さない。BH-035）、文脈の見積もりと上限、読んだプロジェクトの指示のファイルを示す。
- `/compact [指示]`: `Agent::compact` を呼ぶ。処理中は状態の行に示し、ESC で取り消せる。結果（済んだ、圧縮するものがない、取り消した、失敗した）と、要約した項目の数と残した項目の数を一行で示す。
- `/rewind`: 時点の一覧（新しい順、番の番号、理由、時刻、依頼の先頭）を選択の画面で示し、↑・↓ と Enter で選ぶ。次に、範囲（「files and conversation」「files only」「conversation only」）を選ぶ。圧縮の前の時点は「files only」だけを選べる。選んだら、戻せないもの（選んだ時点の後の実行の一覧）と、戻す前の状態も時点として記録することを示し、`[y]` で戻す。結果（戻したファイルの数、消したファイルの数、戻せなかったものの一覧）を示す。選択の画面は ESC でやめる。
- `/new`: 今のセッションを終え（`session_end` を書き、一時ディレクトリを消す）、同じ起動の指定で新しいセッションを始める。前の画面の出力は端末の履歴に残る。
- `/quit`: 終える。一連の処理の途中なら、二度の ESC と同じく止めてから終える。
- モードを変えるコマンドと、提供者やモデルを変えるコマンドは設けない（05-02）。

### 3. 安全の性質のテストを通し直す

- 07-01 の安全の性質のテストのうち、P4 で加えた主のプロセスの操作（圧縮の会話の書き換え、再開、巻き戻しの書き戻しと削除、`web_fetch`、確認の画面、入力の履歴のファイル）に当たるものが、各作業でそろっているかを一覧にして確かめ、足りないものを加える。一覧は完了の報告に書く。

## テスト

- コマンドの解釈: 知らない名前、`//` の扱い、処理の途中で使えないこと、引数の受け渡し（`/compact` の指示が要約の依頼に入る。模擬の提供者で確かめる）。
- `/status` の表示の内容（端末なしで、描画の純関数で確かめる）。トークンの量が集計と一致する。
- `/rewind`: 選択の画面のキーの操作、圧縮の前の時点で範囲が「files only」に限られること、`[y]` でなければ戻さないこと、戻した結果の表示。模擬の提供者と一時のプロジェクトで、ファイルと会話が選んだ時点に戻る。
- `/new`: 新しいセッションの ID になり、前のセッションの記録に `session_end` が書かれ、前の一時ディレクトリが消える。
- `/quit` が処理の途中でも端末を元に戻して終える。
