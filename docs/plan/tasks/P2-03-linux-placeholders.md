# P2-03 Linux の塞ぐ場所の錠と記録、入れ子の探索の時間（BH-095）

## 目的

Linux の bubblewrap の形で、塞ぐために作らせた空のディレクトリ（書ける場所の根の直下のまだない `.git` と `.benitoiteh`）の後始末を、並んで動く子プロセスと `benitoiteh` の強制終了に耐える形にする（設計書 03-02 の「Linux のファイルシステムの見え方」、2026-10-17 の方針）。あわせて、すでにある入れ子の守る場所を探す時間を測る（BH-095）。

## 作るもの

### 1. 錠と記録

- `SandboxCommand::prepare` に、錠と記録を置くディレクトリ（`placeholders`）を引数で渡す。新しい形は `prepare(&self, helper: &Path, scratch: &Path, placeholders: &Path)` とする。ディレクトリがなければ権限 700 で作る。`probe_linux` も同じ引数を取るか、内部で書ける場所を持たない方針だけを使うかは任せる（どちらにしたかを報告に書く）。
- 塞ぐ場所の候補（書ける場所の根の直下の守る名前）ごとに、場所の絶対パスの SHA-256 の 16 進を名前にした錠のファイル（`<hash>.lock`）を開き、`rustix::fs::flock` で共有の錠を掛ける。錠は、その場所があるかを調べる前に掛け、`Cleanup` が持ち、子プロセスの終わりまで持つ。錠を掛けるのは塞ぐ候補の場所だけでよい（すでにあるものとして重ねる場所にも掛けるかは任せる。掛けるなら同じ規則にする）。
- まだない場所を塞ぐと決めたら、bubblewrap を起動する前に、記録のファイル（`<hash>.path`。中身は場所の絶対パスの UTF-8 の文字列）を、同じディレクトリの一時ファイルに書いてから名前を付け替える形で置く。
- 子プロセスが終わった後の後始末（`Cleanup::finish`）は、場所ごとに次のとおりとする。
  1. 共有の錠を、排他の錠（`LOCK_EX | LOCK_NB`）に掛け直す。取れなければ、その場所は消さず、記録も残し、共有の錠を外す。
  2. 取れたら、場所をリンクを辿らずに調べ、空のディレクトリなら消す。空でない、ディレクトリでない、シンボリックリンクのときは消さない。
  3. 記録を消し、錠を外す。錠のファイルは消さない（消すと、ほかのプロセスが同じ名前の別のファイルに錠を掛けうる）。
- 子プロセスを準備するとき（`prepare` の初め）に、`placeholders` の記録を調べ、排他の錠を取れたものについて 2 と 3 を行う（強制終了の残りの片付け）。記録の中身が絶対パスでない、読めないものは、記録だけを消す。
- 錠と記録の操作の誤りは、準備の誤り（`SandboxError`）として返し、子プロセスを起動しない。後始末の誤りは、今と同じく返す。

### 2. 入れ子の探索の時間

- `scan` が辿る項目の数と時間を測る道具を、無視するテスト（`#[ignore]`）として `tests/sandbox_linux.rs` に作る。次の二つの木について、`build`（`prepare`）を 20 回呼んだ中央値と、辿った項目の数を、テストの出力に書く。
  - 項目の少ない木（ディレクトリ 10、ファイル 100）。
  - 合成の大きな木（深さ 3 まで、各段の各ディレクトリに 30 のディレクトリと 30 のファイル。おおよそ 5 万 6 千の項目）。
- この道具は Linux でだけ動くので、オーケストレータが x86_64 の機械で走らせる。Codex の中では走らせなくてよい。

## テスト

`tests/sandbox_linux.rs` に加える。

- 並んで動く二つの子プロセス A と B が、同じ書ける場所のまだない `.benitoiteh` を塞ぐ。A を終わらせて後始末した後も、B の中から `.benitoiteh` に書けず、名前の付け替えもできない。B が終わった後に、空のディレクトリと記録が残らない。
- 同じ並びで、錠を使わずに消した場合に B の塞ぎが外れることを確かめるテストを、無視するテスト（`#[ignore]`）として置く。理由: 錠が要る理由（ほかの名前空間のマウントの場所を消すとマウントが外れること。BH-095）を、オーケストレータが x86_64 の機械で一度確かめて設計書に書くためである。
- 強制終了の残り: 記録と空のディレクトリを手で作っておき、次の `prepare` が片付ける。空でないディレクトリ、ファイル、シンボリックリンクは消さず、記録だけを消す。ほかのプロセスが共有の錠を持っている間は、片付けない。
- 既存の、塞ぐために作らせた空のディレクトリが子の終了の後に消えるテストが通る。

ユニットテスト（`mounts/tests.rs`）は、記録のファイルの名前（ハッシュ）と、記録の中身の検査（絶対パスでないものを消すこと）の境界を確かめる。

## 確かめること

- 錠を使わずに消したときに B の塞ぎが外れるか（無視するテストの結果。オーケストレータが走らせる）。
- 探索の時間の中央値（二つの木。オーケストレータが走らせる）。
- `placeholders` の権限が 700 であること。

## 完了条件

- `scripts/check.sh --inside-codex` が通る。
- 完了の報告に、`prepare` の新しい形と、`probe_linux` の扱いを書く（オーケストレータが 10-interfaces を更新する）。
