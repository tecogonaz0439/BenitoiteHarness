# 文書

設計書、実装プラン、共通の作業手順を次の場所に置く。設計の判断と未決事項は設計書、作業の状態は実装プランを正とする。

| 場所 | 内容 |
|---|---|
| [design/](design/README.md) | 試作の設計書と未決事項 |
| [plan/](plan/README.md) | 試作の実装プラン、作業の状態、検査の結果 |
| [workflow/](workflow/README.md) | 共通依頼文、作業文書の雛形、文書構成の対応表 |
| [評価の道具](../tools/skill-eval/README.md) | 評価の走らせ方と結果 |
| [性能の測定](../tools/perf/README.md) | 実行ファイルの大きさ、起動と応答の処理の測定 |

Benitoite のリリースから取り込んだ文書は `assets/benitoite/` に置き、[取り込む文書と版](design/04-benitoite/04-01-benitoite-integration.md#取り込む文書と版)で出典を管理する。
